# The Mailer

A polished, responsive email client prototype inspired by modern web mail.

## Run locally

Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Responsive desktop and mobile inbox
- Search, folders, stars, unread states, and mail selection
- Full-message reader
- Compose, send, and discard flows
- Keyboard-friendly controls
- No external dependencies

> This is a front-end prototype using local in-browser data. It does not send real email or store accounts/data on a server.
